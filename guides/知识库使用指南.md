# 知识库使用指南

## 目录结构

```
碎片/      inbox          — 快速捕获的灵感和想法
日常/      daily          — 每日记录
笔记/      notes          — 学习笔记和想法
├─ 学习笔记/ learning     — 学完后的总结输出
└─ 想法/    ideas         — 从模糊点子到成型想法
项目/      projects       — 项目方案与复盘
周报/      weekly         — 每周回顾
指南/      guides         — 知识库使用指南
```

## CLI 命令速查

```bash
# 写入
note capture "突然的想法"          # 快速捕获碎片 → 碎片/
note daily                         # 今日日常记录 → 日常/
note new learning "Rust 所有权"    # 新建学习笔记 → 笔记/学习笔记/
note new idea "一个点子"           # 新建想法笔记 → 笔记/想法/
note new project "项目名"          # 新建项目设计 → 项目/<名>/
note weekly                        # 写周报 → 周报/

# 管理
note mkdir "新目录名"              # 创建新目录（自动生成 index.md）
note mv <笔记> <目标目录>           # 移动笔记到指定目录

# 发布
note timeline                      # 刷新时间线
note publish                       # 构建 + 推送 → 更新网站
```

## 命令详解

### note capture "内容"

快速捕获碎片想法，追加到 `碎片/` 下当天日期的文件中。

> 适合突然冒出的点子，不用管格式，先记下来。

### note daily

打开或创建今日日常记录，文件位于 `日常/YYYY-MM-DD.md`。

### note new \<type\> "标题"

从模板生成结构化的笔记：

| 类型 | 模板 | 生成位置 |
|------|------|---------|
| `learning` | `learning-note.md` | `笔记/学习笔记/标题.md` |
| `idea` | `idea-note.md` | `笔记/想法/标题.md` |
| `project` | `project-design.md` | `项目/<项目名>/标题.md` |

### note weekly

生成本周周报 → `周报/YYYY-Www.md`。已有则直接打开。

### note mkdir "目录名"

创建新目录，自动生成 `index.md`（带中文标题），目录名自动转为英文 slug。

```bash
note mkdir "读书笔记"   # → 创建 读书笔记/ 目录 + index.md
```

### note mv \<源\> \<目标\>

移动笔记到其他目录。

```bash
note mv inbox/2026-07-18.md notes/learning/   # 碎片 → 学习笔记
note mv notes/ideas/一个点子.md projects/      # 想法 → 项目
```

### note timeline

扫描所有笔记，按创建时间倒序生成 `timeline.md`。`note publish` 会自动执行。

### note publish

构建网站 + 推送到 GitHub Pages。流程：刷新时间线 → 构建 → 同步到 docs/ → 提交并推送。

## 模板说明

| 模板 | 用途 | status 流转 |
|------|------|-----------|
| `capture.md` | 碎片想法 | — |
| `daily.md` | 日常记录 | — |
| `learning-note.md` | 学习笔记 | seedling → budding → evergreen |
| `idea-note.md` | 想法成篇 | seed → sprout → evergreen |
| `project-design.md` | 项目设计 | ideation → designing → building → shipped → archived |
| `weekly-review.md` | 周报 | — |

## 本地开发

```bash
npx quartz build              # 构建到 public/
npx quartz build --serve      # 本地预览 http://localhost:8080
note publish                  # 完整发布流程
```
